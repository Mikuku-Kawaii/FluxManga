No complete dictionary or upstream executable code is bundled with FluxManga.

FluxManga implements a JSON format reader using existing platform APIs. Users
select a dictionary file, inspect its self-declared revision, measured SHA-256
and entry count, and explicitly replace the app-owned name index. Only namespace,
original label and translated name are retained. Descriptions, links, images and
markup are not rendered or fetched. The source file is unchanged. No automatic
network update, remote query translation or usage reporting is performed.

The upstream README requests a downstream usage issue before using its database.
No issue has been sent by this task. Any future data bundling/distribution or
maintainer communication requires separate release preparation and authorization.
This format integration is not a claim of permission to relicense that data.

Local implementation: GalleryTags.kt, GalleryTagsPage.kt, GalleryTagsPicker.kt,
private AtomicFile storage, existing gallery detail/search/settings and navigation.
Updates are user-selected replacements; failures before commit retain the old file.
No tests, compilation, packaging or device/live-manga-service access this stage.
