Local modifications:
- Ported HTML contracts to existing Kotlin/jsoup repositories and Compose pages.
- Explicit member ID/pass hash inputs; verify current forum identity and gallery
  favorites access before sealing credentials in the private world's storage.
- Stable account/gallery identity, server-provided list links, separate favorites
  categories, explicit current-batch import preserving existing records.
- Gallery pages collected sequentially; individual image-page HTML resolved on
  demand. Display/original caches are distinct. Original image access requires
  an explicit setting and the server-provided fullimg link.
- Existing Rust transport handles bounded HTTPS responses and limited media
  redirects, removing cookies at external destinations. No EX fallback, shared
  WebView cookie store, new database, downloader, Cronet or runtime dependency.
- Existing encrypted image pipeline, Android region decoding, four reading modes,
  progress, statistics, library groups and navigation are retained.
