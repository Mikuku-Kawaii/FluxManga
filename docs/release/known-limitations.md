# 已知限制

- 0.1.2 是早期公开版本。本轮完成 release 构建与产物校验，未进行全功能、设备、读屏或性能验收。
- 图源网站可调整域名、验证方式、接口和访问权限；账号成功连接不代表所有内容都有访问权。单源失败保留独立重试。
- 包子书架导入受官网可见列表范围限制，动态分页不能保证完整；Komga 不提供首页推荐；PicACG 没有已确认可接回的网页登录入口。
- EX 权限与 EH 分开验证。私有图源需要有效空间会话，私有下载沿用前台加密路径，不套用公开来源后台通知。
- 网络慢或下一话预加载失败时仍需等待 / 重试；不会为了“连读”跳过未加载或未下载章节。
- 当前发行与 Rust 绑定生成脚本面向 Windows x64。Linux / macOS 构建未提供对应脚本。
- 首个 GitHub 发行只提供完整包；差分更新需后续同签名基线与更高版本实际产物。
- 应用禁止 Android 自动云备份。跨设备恢复需要主动使用已实现的备份 / 导出功能，原设备 Keystore 密钥不能直接复制到新手机。
- 同名作品不会跨图源自动合并。取消收藏、移除应用副本与删除原文件的含义不同，导入与界面修改不会删除原文件。
- 安装与更新必须由 Android 确认；签名不一致时无法直接覆盖，不以卸载绕过。旧预览版没有更新地址，或 0.1.0 / 0.1.1 下载即失败时，需手动覆盖安装 0.1.2 一次。

反馈请附版本、Android 版本、重现步骤及脱敏错误，不上传账号会话或私有阅读内容。
