# 图源维护与固定上游

[source-adapters.json](../third-party/source-adapters.json) 与各适配 NOTICE 保存固定提交、许可及采用范围。索引中的历史哈希和评估路径记录当时状态，不代表当前代码未变化；私人运行记录与本机上游缓存不随公开仓库发布。

维护图源时，先定位实际失败端点和受影响能力，再比较固定上游与修复提交。选择必要协议适配，保留来源、原版权、完整许可及修改说明；不要为一个来源引入另一套数据库或完整扩展宿主。

修改必须保留空间 / 来源 / 作品组合身份、会话 generation、取消、分页和单源失败语义。认证凭据只交给其对应服务，网页验证成功与 API 身份核验分别处理。未知响应不能当作空账号或导入成功。

提交时更新对应 NOTICE、能力说明及版本记录。历史依赖快照不伪装成新的实际构建清单。服务验证按明确任务范围进行，不将源码完成或构建成功称作所有图源可用。

图源实现随应用 APK 更新；当前没有脚本扩展宿主或图源热更新服务。应用更新流程见 [GitHub 自动更新与发布](github-updates.md)。
