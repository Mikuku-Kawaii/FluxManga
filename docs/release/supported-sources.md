### 漫画柜列表失败定位与修复

用户反馈推荐/搜索即失败，提示“图源安全连接失败”。同一 OPPO 上定向诊断发现：代理开启时握手 EOF；关闭代理后系统将 `www.manhuagui.com` 解析到 `185.45.7.189`，请求超时。同机保留原 Host/SNI 和证书验证连接 `107.189.8.124` 能收到 200；其公开别名 `www.mhgui.com` 在该网络正好解析到可用地址。证据支持域名解析/网络路径问题，不是列表 DOM 变化。

实现复用现有 reqwest `Resolve` 和 Tokio 系统解析，仅给漫画柜客户端的 `www.manhuagui.com` / `tw.manhuagui.com` 优先采用本站别名 `www.mhgui.com` 的解析结果；别名解析失败/空结果回到原系统解析。请求 URL、证书验证、Host/SNI、来源键与会话取消契约不变。CDN 和其他来源继续用原解析；无固定漫画柜 IP、无额外依赖、数据库或全局网络设置变化。每次新连接可能增加一次别名 DNS 查询，连接池沿用原实现，性能未实测。

将同一解析模块用于手机只读诊断，推荐/更新/搜索均为 HTTP 200，分别出现 42 / 42 / 10 张列表封面的 HTML 标记。该结果仅覆盖网络与公开页面结构；修复尚未构建 APK 或覆盖安装，未做应用 UI、账号登录或整套回归。


### 账号接入实施选择（2026-11-11）

本轮获授权实现三源登录。复用本项目 AccountWebLogin / BrowserPasswordManager、WorldDataStore 密封会话、WorldSession 生命周期与 reqwest HTTP，不复制 Venera 未明确许可代码或 moon GPL 代码，不新增运行时、数据库或扩展宿主。仅依据官网表单和账号校验响应适配：瓜子网页登录＋用户中心；快看网页登录＋ `/v2/pweb/user_info/get`；漫画柜原生表单 POST `user_login`＋`user_check_login`。漫画柜原生登录沿用已修复的 DNS 路径。普通公开目录仍可匿名，账号 Cookie 只发到对应官网元数据和校验地址，不发 CDN 或快看搜索 API。性能预估为惰性加载一份加密会话，登录/切换后失效该源客户端；未作性能测量。
