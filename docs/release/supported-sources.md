# 已接入图源

图源配置、登录、注册入口和收藏导入集中在「设置 → 图源管理」。同空间的推荐、搜索、更新与标签结果混合展示，每个来源保留独立身份、分页和失败重试。已实现能力不等于所有服务、账号和设备均已验证可用。

| 来源 | 浏览与阅读 | 账号与导入边界 |
| --- | --- | --- |
| 本地 CBZ | 归档校验、自然页序、封面、四模式阅读和续读 | 保存应用副本，保留用户原文件 |
| Komga | 搜索、更新、标签、详情、章节与正文；无图源推荐接口 | 用户配置服务器；API Key / Basic 及受支持网页会话，授权 library / collection / read list 导入 |
| 拷贝漫画 | 推荐、更新、搜索、标签、封面、分页目录与正文 | 应用内网页登录后连接官网会话；云收藏 `free_type=1`、21 项分页；原生 API 密码登录存在兼容问题 |
| 包子漫画 | 官网推荐、更新、分类、搜索、详情、章节与正文 | 官网登录 / 注册及验证后接回本站会话；导入官网可见书架。可靠空书架身份与完整分页仍缺协议依据 |
| JMComic | 推荐、更新、关键词 / 编号搜索、分类、详情、章节与图片切片还原 | 里世界；账号或受支持网页登录接回，收藏文件夹与分页导入；API 与图片 CDN 自动尝试可用线路，换线保留账号 |
| PicACG | 推荐合集、榜单、最新、分类、搜索、详情与阅读 | 里世界；邮箱 / 密码与密封 Token，收藏分页导入；未提供无法核实的网页登录入口 |
| E-Hentai | 搜索、原始标签、详情、画廊图片与可选原图 | 里世界；论坛身份与本站收藏核验、网页会话接回、收藏分类 / 游标导入 |
| ExHentai | 独立画廊访问、搜索、标签、图片与原图 | 里世界；独立核对 EX 权限和会话，EH 成功不能代替 EX 成功；独立收藏、进度和缓存 |

导入支持取消、续办、去重及补齐作品资料，不覆盖已有收藏或阅读位置；这不是远程阅读进度双向同步，也不承诺迁移网站的全部私人数据。同名作品不自动合并身份。

表世界下载支持后台队列与通知。里世界逐页加密下载仅在下载页前台执行，不生成持久明文正文；正文、凭据和空间状态使用原有隔离路径。四种阅读方式、书签、统计、续读和连续章节复用共同阅读器。

EH / EX 另有网站收藏操作、评论和用户导入中文标签词库入口。词库采用其原始许可，APK 不内置完整词库；未知标签保持原文。站点挑战、配额、权限不足和未知响应显示失败，不自动跨来源代替成功。
