## 认识 FluxManga

### 发现下一部想读的作品

首页采用封面主视觉：顶部滑动浏览图源推荐，下方以网格展示最近更新和更多推荐；表里空间沿用同一布局和各自色卡。首页网格保持封面尺寸与字号，分区和网格行间距收紧为 8dp；封面下的资料紧跟标题，缺失字段跳过，各行继续整齐对齐。推荐使用真实图源结果，表世界优先展示拷贝结果；紧凑横向推荐卡点击即可进入详情，保持卡片整体高度，左侧封面铺满卡片高度并贴齐左边缘，右侧展示标题、作者、标签、章节数 / 状态和简介；标题按实际换行宽度选择较大单行或较小双行，不再用固定高度裁切第二行，双行仅在第二行末尾省略；标题统一顶对齐，单行优先使用 20sp 字号和 28sp 行高，双行保持 16sp / 22sp；右侧剩余高度均摊到实际信息块之间；有简介时单行标题对应三行简介、双行标题对应两行简介，作者与标签各一行，缺失资料不占位，大字时可在信息区内滚动。当前可见卡片按需补取资料并按空间缓存，下拉刷新更新资料，拷贝章节数使用接口的分组总数。里世界推荐与表世界共用同一封面、标题、资料间距与简介行数规则，保留各自配色和缓存隔离；资料不再等待封面加载，PicACG 先显示作者、标签和简介，再补齐分页目录的章节数，未知章节数不显示为零。封面失败提示和重试收在封面内，不再挤动卡片布局。最近更新只显示实际返回的章节信息，缺少章节名时不显示占位提示。按关键词或标签寻找漫画。多个来源的结果可以一起查看，每个来源独立加载；你也可以进入单个来源浏览。找到喜欢的作品后，将它加入书库，或者从已有图源账号导入收藏。

### 把喜欢的作品整理成自己的书库

书库的「筛选与排序」支持按阅读时间、书名或本地导入时间排列，并可选择「正序 / 倒序」。时间正序由早到晚、倒序由晚到早；缺少对应时间的书目仍排在后面。各排序条件的方向按空间记住，面板不再提供「下载状态」筛选。

在线漫画和导入的本地 CBZ 都可以放进书库，以网格或列表浏览。使用收藏、标签和分组整理作品，从最近阅读的位置继续；书库根据可获得的目录，在阅读状态后追加“ · 有未看章节”；更新日期统一以灰色显示，已完结作品显示“已完结”。

书库的“收藏”和阅读状态筛选区域在常规、批量模式下都会吸顶固定，书目数量紧接标题右侧。长按书目进入多选，原有布局和操作保持，数量后追加“已选 N 部”，筛选下方增加“全选、清空、取消收藏、取消”，共用筛选栏的文字按钮样式。本地 CBZ 导入时会保存应用副本，原文件保留在原处。

图源的「收藏导入」以封面网格展示作品，支持搜索已加载收藏、筛选全部 / 未入库 / 已入库和选择导入。导入操作与进度位于底部，资料补齐、重新扫描和任务详情收在右上角。Komga 先选择授权列表；包子按网站已返回的书架导入，其他来源保留各自的分页和整账号导入范围。

拷贝账号只用于登录和读取云收藏，新导入书目沿用应用现有的拷贝阅读图源，不把网页登录来源带入阅读。已导入书目兼容原有标识，保留收藏和进度，详情、章节、封面与正文同样使用现有阅读接口；重复导入优先复用已有书目。

PicACG 在「图源管理 → PicACG → 账号」直接提供网页会话 Token 输入与导入，浏览器登录 / 注册地址恢复为 [manhuabika.com](https://manhuabika.com/)。用户反馈新域名的应用内网页仍然白屏，本次改为手动 Token 登录：在电脑浏览器登录后，从开发者工具的本站本地存储复制 `token`，在应用内粘贴；身份核验通过后加密保存并进入原收藏导入页，空收藏属于正常结果，失败保留原账号和输入。应用内登录收进备用入口，API 账号密码表单保持移除。作品、搜索、详情、章节和收藏继续使用固定 `https://picaapi.go2778.com/`，图片映射、来源身份、书库及阅读进度保持不变。

PicACG 备用网页登录新增「网页加载诊断」：分类显示子资源网络错误、HTTP 状态、控制台 CORS / CSP / 模块 / Service Worker 消息，以及页面 Origin、根节点和 Service Worker 网络策略 / 支持 / 接管状态。只在当前窗口内保存最多 10 条脱敏事件，导航或关闭即清除，不保存完整 URL、控制台原文、请求头、正文或账号信息；子资源失败不直接判定整个登录失败。HTTPS、证书、同源与域名约束保持不变。公开无凭据预检发现 `/users/profile` 只返回 `Access-Control-Allow-Headers: *`，未显式包含 `Authorization`，是需要关注的跨域配置疑点（[规则](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Access-Control-Allow-Headers)），尚无手机端 CORS 拦截证据，不能认定为首次白屏根因。本版尚未在设备上验证该诊断功能。



### 按自己的习惯打开应用

「设置 → 启动与返回」使用独立启动图标和页面，与其他设置子页共用页头和返回导航。可以选择默认打开首页、书库、标签或上次使用的主页面，也可以关闭「退出后返回表世界」，保留上次使用的空间。自动返回开启时，可选立即、30 秒、1 分钟或 5 分钟的后台等待时间；默认仍为首页、自动返回开启、30 秒。选项沿用即时保存，默认主页面在下次启动时生效。

重新启动只恢复空间和主页面，不恢复私密详情或阅读页。后台遮挡、加密存储和已开启的生物识别验证保持生效。

### 用喜欢的方式阅读


图源章节名为空时，目录、阅读器标题和下载选择统一按章节序号显示「第 N 话」；反转目录或筛选不会重新编号，已有章节名、章节 ID 和进度保留。拷贝与包子不再因章节名称为空而拒绝整份目录。来源明确标注已完结的在线作品，在确认没有下一话、末页图片实际显示后自动归入书库「已读」；条漫需显示到末页底部，预加载不触发，连载或完结状态未知的作品不会被误标。完成标记按空间保存，不覆盖阅读位置，后续目录确认同组新增章节时不再视为整部读完。

表世界详情标签按标题实际行数折叠：单行标题最多两行标签，多行标题最多一行，展开时打开标签弹窗。里世界详情标签默认最多两行，不受标题行数影响；超出两行才在第二行末显示「展开」，点击后原位展开 / 收起。里世界详情页不再显示「图源与账号设置」，相关设置仍可从图源管理进入。详情标题和下方资料靠上紧密排列，不用均分间隙强行对齐到底；横排封面保持比例裁切，允许右侧底部留白。

表世界作品即使只有 1 话也显示章节目录和入口；里世界保留原有单话隐藏规则。

进入阅读器直接显示黑底加载画面，加载完成后保持全屏，轻触画面即可打开章节、书签和页码工具。你可以选择左右翻页、从右向左翻页、上下逐页或条漫模式，也可以缩放、使用音量键翻页，或在宽屏上使用双页。

阅读位置和阅读方式按作品保存。接近章节末尾时会预加载当前章节目录内的下一话，让阅读自然续接；到达当前目录最后一话后显示过渡页，再翻一页返回漫画详情，拷贝的默认、单行本等目录之间不自动跳转；支持下载的章节也可以离线阅读。最近观看统一从「设置 → 最近观看」查看，首页不再展示记录；进入详情或阅读页会按空间保存浏览记录，包括缓存、离线和直接续读入口，不改动收藏与阅读进度。阅读统计可用于回顾自己的阅读时间。

### 两个空间，两份书库

表世界采用清爽的白蓝配色，里世界采用黑橙配色。两个空间各自保存书库、阅读进度、图源账号和缓存，可以按需要切换。

里世界提供加密存储、窗口保护和可选身份验证。液态玻璃界面、切换动画与低效果选项可在设置中调整；漫画正文不会被模糊处理。空间保护不能代替设备本身的安全设置。

## 支持的来源

| 来源 | 适合做什么 | 使用前需要知道 |
| --- | --- | --- |
| **本地 CBZ** | 导入自己的漫画文件，离线阅读 | 应用保存副本，原文件保留 |
| **Komga** | 浏览和阅读自己的漫画服务器 | 需要自行配置服务器及访问凭据 |
| **拷贝漫画** | 浏览、搜索、阅读和导入云收藏 | 支持应用内网页登录；导入范围取决于可用接口 |
| **包子漫画** | 浏览、阅读和导入网站书架 | 网站可能要求登录或浏览器验证，书架导入范围以网站返回为准 |
| **JMComic** | 在里世界浏览、搜索、阅读及导入收藏 | 可用线路和内容取决于服务与账号 |
| **PicACG** | 在里世界浏览、搜索、阅读及导入收藏 | 浏览器打开 [manhuabika.com](https://manhuabika.com/) 登录 / 注册，账号页手动导入 Token；应用内登录作为备用 |
| **E-Hentai / ExHentai** | 在里世界搜索、阅读画廊及导入收藏 | ExHentai 权限需要单独确认 |

各来源的功能、登录方式和导入范围不同，访问也会受到站点、账号权限及网络影响。FluxManga 不提供漫画资源、账号或服务镜像。[查看详细图源说明](docs/release/supported-sources.md)。

包子支持会话恢复：保留独立网站会话，过期后先恢复网站验证，确需登录时才使用已保存的自动登录凭据。恢复成功会接续失败的读取；需要人工验证或修正密码时，可在图源设置中处理。旧版 WebView 使用兼容的 Cookie 恢复方式。已有账号、书库和阅读进度保留。

## 下载与安装

从 [GitHub Releases](https://github.com/Mikuku-Kawaii/FluxManga/releases/latest) 下载 **FluxManga-1.1.1-universal.apk**。

- 需要 **Android 12 或更高版本**；安装包支持 arm64-v8a 和 x86_64。
- 首次安装时，按 Android 的提示允许相应来源安装应用。
- 从同签名的旧版升级时，可直接覆盖安装并保留应用数据。若遇到签名冲突，请先核对安装包来源。

应用启动时会检查更新，也可以在「设置 → 关于与更新」手动检查。下载完成后，应用会校验安装包，再由 Android 系统确认安装。

## 开始使用

1. 安装并打开应用，在首页浏览推荐，或通过搜索和标签寻找作品。
2. 打开「设置 → 图源管理」，按需连接图源账号或配置 Komga 服务器；可在对应来源导入已有收藏。
3. 在书库中添加本地 CBZ、管理收藏和标签，或从上次阅读的位置继续。
4. 阅读时轻触画面，切换阅读方式、查看目录、添加书签或跳转页码。
5. 需要不同的书库与账号时，切换表世界和里世界，再分别配置来源。

应用提供备份与记录导出入口。更换设备前，请主动备份需要保留的数据，并妥善保存本地漫画原文件。

## 给开发者

界面使用 Jetpack Compose，Android 层负责生命周期、数据和图片处理；部分核心能力与图源协议由 Rust 提供，通过 UniFFI 与 Kotlin 连接。

当前构建脚本面向 Windows x64。配置 JDK 17、Android SDK、NDK 和 Rust 后，可运行：

```powershell
.\gradlew.bat :app:assembleDebug
```

完整环境、发行签名与安装说明见[构建文档](docs/release/build-and-install.md)。自行签名的构建通常不能覆盖官方安装包。
