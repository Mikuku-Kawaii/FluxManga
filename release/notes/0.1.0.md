# FluxManga 0.1.0

首个 GitHub 公开版本，支持 Android 12+，包含 arm64-v8a / x86_64 两种 ABI。

- 本地 CBZ、双空间书库、多图源混合搜索与推荐。
- 图源账号连接、收藏 / 书架导入、封面和作品信息缓存。
- 全屏阅读、四种阅读方式、正文连读、接近末尾预加载下一话；最后一话后显示结束页。
- 内容页面首载布局占位、刷新保留已有内容、失败原因与刷新入口。
- 下载、书签、阅读统计、分组与记录导出。
- GitHub 签名更新清单、完整包下载 / 续传、APK 身份校验及系统安装入口。

显示版本 0.1.0，内部 versionCode 3；沿用既有预览签名，兼容同签名旧包覆盖升级。未配置更新渠道的旧预览版请手动安装本次 APK 一次。请保留原文件，不要卸载或清数据。

这是早期公开版本；本轮执行发布构建与产物检查，没有运行设备、功能、TalkBack 或性能测试。图源可用性由网站、账号权限和网络决定。首版只发布完整 APK，尚无公开差分基线对。
