# FluxManga 0.1.1

本次更新增强阅读中的当前章节预加载：

- 持续逐页缓存当前章，优先当前位置及后续页，再补齐前段；表里世界共用相同调度。
- 下一章仍按原规则在接近章末时预热前三张图；实际进入下一章后才开始该章的整章预加载。
- 复用已有图片文件及私有加密缓存，不将整章解码到内存，不推进未阅读页面的进度。
- 后台、离页或换章时取消预加载；恢复后复用缓存，单页失败保留阅读时的错误与重试入口。

版本 0.1.1 / versionCode 4，Android 12+，arm64-v8a / x86_64 双架构。沿用 0.1.0 的 APK 签名与更新清单密钥，支持覆盖升级、保留应用数据。

已安装 GitHub 公开 0.1.0 的用户，可在「设置 → 应用更新」检查并下载；安装由 Android 系统确认。本次为完整 APK 更新，不提供差分包。请勿卸载或清理应用数据。
