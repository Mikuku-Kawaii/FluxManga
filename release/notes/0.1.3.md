# FluxManga 0.1.3

针对 0.1.1 里世界条漫“往下才加载、往上又重载”的反馈修正图片管线：

- 当前章预取成功后提前更新图片尺寸，条漫可提前建立分块布局，不等滚到该页再读尺寸。
- 私有图片命中缓存时直接解码，不再等待其他页的后台网络请求。
- 阅读入口保留最近解码分块（24 MiB 上限），回看优先复用；条漫额外预热当前章节屏幕下方两块。
- 图片显示使用章节 / 页 / 尺寸 / 分块稳定键，尺寸信息补齐不重置已经显示的同一图片。
- 整章仍以编码文件 / 私有加密缓存保存，不把整章全部解码到内存。后台和退出清除解码缓存，原书库、进度、加密约束保持。
- 跨章规则不变：近章末预热下一章前三张，实际进入后才开始下一章整章预取。

版本 0.1.3 / versionCode 6，包含 0.1.2 更新下载器修复。沿用相同 APK 签名和更新密钥，Android 12+，双 ABI 完整包，无差分产物。

**测试应用内更新：若仍在 0.1.0 / 0.1.1 且点击下载就失败，先从历史 Release 手动覆盖安装 0.1.2，再在应用更新页检查并升级至 0.1.3。也可直接手动覆盖安装本版。不要卸载或清库。**

本轮仅源码检查、发布构建及产物核对；没有设备或功能测试，条漫实际体验和安装更新结果由用户确认。
